шпаргалкаСвой ролик в стиле любого моушна

Выбери свою версию Claude — шаги ниже подстроятся. Переключатель всегда наверху.

0 / 7
Платный Claude (Pro)
  • Claude сам скачивает ролик и смотрит его по кадрам — стиль повторяется точнее
  • Сложные движения: 3D, фото, много сцен
  • Готовое видео сразу файлом MP4
  • Правок — сколько нужно
Бесплатный Claude
  • Ничего не платишь
  • Хватит на простой ролик: текст + фигуры, 2–3 сцены
  • Кадры ролика показываешь Claude скриншотами
  • Видео сохраняешь записью экрана, правок — 1–2: лимит небольшой
1

Подготовь Claude

  1. Нужна подписка Pro (или выше). При отправке сообщения выбирай модель Opus — внизу, у поля ввода.
  2. Один раз разреши Claude заходить на сайт с роликами: claude.ai → своё имя слева внизу → Settings → Capabilities.
  3. Включи Code execution and file creation.
  4. Ниже, в поле Additional allowed domains, добавь по очереди две строки (вписала → нажала Add):
    prompt-motion.com*.prompt-motion.com
    Нужны обе: на первом адресе сам сайт, на втором — видео.
  1. Открой claude.ai и войди в аккаунт. Ничего настраивать не нужно.
  2. Сделай всё в одном чате от начала до конца — так Claude помнит стиль и меньше тратит лимит.
Итог шага: в настройках две строки с prompt-motion.com.открыт новый чат.
2

Выбери ролик, который нравится

Смотри на движение и настроение, а не на тему — тему ты поменяешь на свою.

  1. Открой сайт prompt-motion.com — это бесплатная библиотека моушн-роликов, сделанных в Claude. Регистрация не нужна.
  2. Открой ролик, который зацепил, и скопируй ссылку на него.
  3. Сделай 3–4 скриншота ролика: начало, середина, конец. Бесплатный Claude не умеет сам скачивать видео — он посмотрит на кадры.
Итог шага: ссылка скопирована и есть 3–4 скриншота.
Совет: для бесплатного Claude бери ролики попроще — с текстом и фигурами. 3D и фото он на бесплатном лимите обычно не вытянет.
3

Попроси разобрать стиль

Claude опишет, из чего сделан ролик, и даст тебе промпт для таких же роликов.

  1. Нажми Скопировать у промпта ниже.
  2. Вставь в новый чат Claude.
  3. Сотри [ссылка] и вставь вместо неё свою ссылку из шага 2.
  4. Нажми + (или скрепку) и прикрепи скриншоты.
  5. Отправь.
промпт 1 · разбор стиля
Разбери стиль моушн-ролика: [ссылка]

Скачай видео со страницы и посмотри его по кадрам.
Коротко опиши: настроение, цвета, шрифты, как всё двигается, сцены по секундам.

В конце напиши готовый промпт, по которому можно сделать ролик в этом же стиле на любую тему.

Прикладываю скриншоты из него: начало, середина, конец.

В конце напиши короткий промпт, по которому можно сделать простой ролик в этом стиле на любую тему: 2–3 сцены, текст и фигуры.
Итог шага: Claude прислал описание стиля и в конце — готовый промпт.
4

Проверь разбор

  1. Прочитай описание. Похоже на ролик, который ты выбрала?
  2. Если нет — напиши обычными словами, что не так. Например: «цвета там тёмные, а не светлые» или «текст там вылетает по буквам». Claude поправит.
  3. Скопируй промпт из конца ответа себе в заметки. Это твой «стиль» — по нему можно делать ролики хоть каждый день.
Итог шага: разбор совпадает с роликом, промпт сохранён в заметках.

6

Сохрани ролик

  1. Claude пришлёт файл MP4 — нажми на него и скачай.
  2. Файла нет? Напиши в чат: «Запиши ролик в MP4 и дай скачать».
  3. Музыку добавь уже в Instagram, когда будешь выкладывать.
  1. Разверни окно с роликом на весь экран (значок в углу окна).
  2. Включи запись экрана:
    iPhoneПункт управления → кнопка записи
    Androidшторка → «Запись экрана»
    MacCmd + Shift + 5 → «Записать выбранную часть»
    WindowsWin + Alt + R
  3. Дай ролику проиграться один раз, останови запись и обрежь лишнее (на телефоне — прямо в галерее).
  4. Музыку добавь уже в Instagram.
Итог шага: видео лежит у тебя в телефоне или на компьютере.
